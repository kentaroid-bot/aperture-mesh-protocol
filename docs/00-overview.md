# Aperture Mesh Overview

## Problem

Many social systems concentrate six functions in one authority:

```text
Rule-making
Oracle / fact recognition
Custody / escrow
Enforcement
Appeal
Exit routing
```

A platform, household authority, corporation, state, or international institution can become dominant when it controls several of these functions and makes participation essential for survival.

## Proposal

Aperture separates those functions and connects sovereign Nodes through machine-readable boundary contracts.

Each Node may have a different internal OS. The protocol does not require identical beliefs, family norms, cultures, political systems, or motivations. It regulates only the interfaces needed for a particular connection.

```text
Node
  exposes: capabilities, boundaries, contract versions, audit commitments
  keeps private: internal OS, unrelated activity, private Monku, internal relationships
```

Nodes can form a Mesh. A small Mesh can then act as a Supernode in another Mesh without exposing or surrendering its internal structure.

## Revolution Definition

Escrow and automatic Tripwires can distribute bargaining power, but automation alone does not create fairness.

```text
Aperture Revolution
  = Distributed Rule-making
  + Independent Oracles
  + Limited / Non-custodial Escrow
  + Reversible Tripwires
  + Independent Appeal
  + Real Exit Alternatives
  + Forkable Protocol
  + Continuous Capture Audit
```

If one actor can write the rule, certify the violation, hold the assets, execute the penalty, deny the appeal, and block Exit, the system is captured even if it uses decentralized technology.

## Household Experiment

Aperture Home is not a miniature nation-state. It is the smallest environment in which people can develop `Embodied Protocol Literacy`:

- distinguish rejection from relationship denial;
- separate majority decisions from personal-rights consent;
- change connection conditions instead of judging personality;
- prefer reversible cooling before strong sanctions;
- treat Revision, Limited Connection, and Exit as normal outcomes;
- recognize when a safety protocol itself becomes controlling.

The final learning goal is not dependence on the app. It is the ability to use these judgments without the app.

## Civilization Scale

```text
Person Nodes
  -> Household Mesh
    -> Inter-Household Mesh
      -> Cooperative / Functional Mesh
        -> City / Regional Mesh
          -> Sovereignty Mesh
            -> Planetary Inter-Mesh Network
```

The intended end state is not one world Mesh or one universal internal law. It is an ecology of overlapping, replaceable, forkable Meshes that can coordinate shared externalities without assimilating their internal systems.

## What This Repository Can Establish

The repository can test protocol invariants, implementation boundaries, failure scenarios, usability, and simulated behavior.

It cannot establish that automated sanctions are just, that a household safety feature is safe in coercive environments, or that a global protocol would produce the political outcomes described. Those require independent research, field evidence, legal and safety expertise, and continued adversarial review.
