# 家庭内自律協調プロトコルアプリ『Aperture Home』UI/UX設計仕様書

## 1. 基本設計哲学
『Aperture Home』は、MonkuAiプロジェクトが提示する**「認識論的アライメント（Epistemic Alignment）」**および**「体制不可知（State-agnostic）なP2Pプロトコル」**の思想を、最も身近な社会単位である「家庭」において実践・訓練するためのアプリケーションである。

家庭内における不和や衝突の多くは、他者の内生領域（感情、価値観、動機）を「コントロール（道徳や規範による支配）」しようとすることから生じる。本アプリは、家族メンバーの「心（OS）」をブラックボックスとして扱い、相互の境界線とインターフェース（API）のみを規定することで、感情的摩擦を極小化し、実務的に家庭を運営することを目指す。

日常的に「境界と契約の心地よさ」を体得することは、将来的に人間の理解を超える超知能（ASI）や、全く価値観の異なる国家・社会（P2P秩序）と共生するための「認知の器（認識論的アパーチャ）」を鍛えるブートキャンプとなる。

## 2. コア機能要件

### ① タスクAPI契約（Task API Contracts）
家族間の家事や役割分担を、道徳的な責任感や感謝の強要ではなく、明確な「APIスキーマ（入力・出力・SLA）」として定義・締結する。
*   **契約スキーマ**:
    *   **メソッド名**: `executeGarbageDisposal` (ゴミ出し)
    *   **入力条件 (Payload)**: 分別済みゴミ袋、指定集積所
    *   **期限 (SLA)**: 毎週火・金曜日 午前8:00
    *   **対価/報酬 (Response)**: 相手ノードによる `executeDishWashing` の優先権、または家庭内リソース（Wi-Fi帯域、リビング優先使用権など）のトークン。
*   **特性**: 「なぜやってくれないの？」という感情的対立を排し、「SLA未達に対する自動プロトコルの執行」として処理する。

### ② クールダウン・トリップワイヤー（Cooldown Tripwire）
心理的・物理的な「境界線（Boundary）」が侵害された場合、感情的な喧嘩に発展する前に、システムが物理的・機械的に関係を一時遮断（クールダウン）する。
*   **トリップワイヤーの例**:
    *   **音声エントロピー検知**: リビングの騒音レベル（デシベル数や声のトーンのトゲトゲしさ）が閾値を超えた場合、スマートスピーカーが自動的に「通信終了（クールダウン状態）」を宣言。
    *   **物理アクセス制限**: 境界侵害が発生した際、スマートキーのAPIが連動し、お互いのプライベートスペース（個室など）への電子錠が強制ロックされ、30分間の非干渉フェーズ（Cooling Phase）へ移行。
*   **特性**: 誰が正しいかをジャッジせず、システムが「トリップワイヤー」として機能し、物理的な距離を自律的に確保する。

### ③ Monku蓄積・変換ビュー（Entropy Reconstitution Engine）
日常発生する「モヤモヤ」「不満（Monku）」を、その場でぶつけて感情を摩耗させるのではなく、一時的にシステムにプールし、高次の契約更新のエネルギーへと昇華させる。
*   **変換フロー**:
    *   ユーザーは音声またはテキストで「感情的な愚痴（Monku）」を吹き込む。
    *   アプリ内のAI（FeedMonkの家庭版）が、不満の背景にある「境界のバグ（APIの設計ミス）」を解析。
    *   週1回の「プロトコル更新フェーズ」において、不満を「新しいタスクAPI契約の提案仕様書」としてリビルドして提示する。
*   **特性**: 失敗や崩壊（エントロピーの上昇）を、システム全体のより頑健な再構成のための燃料（インプット）として扱う。

## 3. 主要画面（UI）構成案

### 【ダッシュボード画面：Aperture Control Panel】
*   **全体の印象**: 北欧風ミニマリズム、ニュートラルで落ち着いた色調（トープ、ソフトグレー、クリーンホワイト）。感情を刺激しない極めてドライで機能的なレイアウト。
*   **ステータス表示**:
    *   **ノード接続状態**: 家族各員のノード（例：Node-01, Node-02）がアクティブに接続されているか。
    *   **システムエントロピー（不満度）**: 家庭全体の未処理エントロピーが可視化されたクリーンなインジケーター。
*   **ウィジェット群**:
    *   **Active Contracts**: 現在履行中の家事API契約とSLA（サービス品質合意）のカウントダウン。
    *   **Boundary Status**: プライバシールームのロック状況やクールダウンカウンター。
    *   **Monku Pool**: 処理を待っている「不満（ノイズ）」の蓄積度合と、そこから自動作成された「契約改善APIスキーマ」の提案リスト。
